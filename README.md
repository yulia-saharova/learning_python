# Изучение Python на примере простых проектов

## Список проектов

1. Консольный калькулятор (папка calculator)
2. Игра «Угадай число» (папка guess_number)

## Консольный калькулятор

Калькулятор — консольное приложение для выполнения базовых арифметических операций.
Технологии: Python 3, обработка исключений, type hints, match-case.

### Возможности

- Поддерживаемые операции: +, -, *, /, ** (возведение в степень)
- Защита от деления на ноль и некорректного ввода
- Повторный запуск без перезапуска программы
- Модульный структура проекта

### Технологии и навыки

- match-case
- Type hints + docstrings
- Обработка ошибок (try/except + валидация)


## Игра «Угадай число»

Угадай число — интерактивная консольная игра с тремя уровнями сложности.
Технологии: Python 3, random, type hints.

### Возможности

- Три уровня сложности:
    - Лёгкий (число от 1 до 50, 10 попыток)
    - Средний (число от 1 до 100, 8 попыток)
    - Сложный (число от 1 до 1000, 6 попыток)
- Отслеживание лучшего результата за сессию
- Полная валидация ввода

### Технологии и навыки

- Работа со словарями и вложенными структурами
- Генерация случайных чисел (random)
- Сохранение состояния игры (best_score)
- Модульная структура проекта
